O Atlasu lokomotiv

Atlas lokomotiv je specializovaný informační web věnovaný elektrickým lokomotivám řad 242 a 371.

Cílem atlasu je přiblížit historii, konstrukci, elektrickou výzbroj, trakční motory, podvozky, brzdové systémy a provozní vlastnosti těchto železničních vozidel.

Web je určen zájemcům o železniční dopravu, studentům dopravních oborů a příznivcům železniční techniky.
